# BoilerPro SA — First Working MVP v6

Boilermaker trade-test preparation app prototype.

## v6 additions
- Added **Round Pipe with Off-Set Square Pipe — 60° (PVW 2-3)** as a dedicated lesson.
- Added the generated technical training image `round-pipe-offset-square-60.png`.
- Added training dimensions: round pipe OD 323 mm / ID 299 mm; square pipe 200×200 mm OD / 188×188 mm inside size; 150 mm offset; 60° intersection.
- Added mean-diameter calculations: round MD = 311 mm; circumference ≈ 977.3 mm using π = 3.142.
- Added square inside-size layout: 188 mm × 188 mm; perimeter = 752 mm.
- Added side-view mean-diameter point method and transfer-to-layout procedure.
- Added long-point-first fabrication sequence before attempting fit-up.
- Retained the 60° PVW 2-3, cone + 90° pipe, bending inside-size rule, and 360° bend-line principle. The 90° round + offset square lesson was removed as requested.

## Scope
Engineering Drawing and Welding remain excluded from BoilerPro SA. Training examples must be checked against the applicable job specification, approved fabrication method and current trade-test requirements.
